# Horizon — экспериментальная сборка для Windows 7 x64

Эта сборка предназначена для проверки совместимости Horizon с Windows 7 SP1 x64 и графикой Intel HD Graphics.

## Запуск

1. Распакуйте архив в отдельную папку.
2. Запустите `Start-Windows7-OpenGL.bat`.
3. Если появится ошибка, сохраните её текст или пришлите снимок экрана.

## Что отличается в этой версии

- Клиент собирается для специальной Rust-цели `x86_64-win7-windows-msvc`, а не для обычной Windows-цели, которая рассчитана на Windows 10 и новее.
- Специальная цель включает слой совместимости Rust для некоторых системных функций, отсутствующих в Windows 7, включая `GetSystemTimePreciseAsFileTime`.
- Используется nightly Rust и сборка стандартной библиотеки из исходников (`build-std`).

## Важно

- Это экспериментальная сборка, а не подтверждённая поддержка Windows 7.
- Исправление ошибки `GetSystemTimePreciseAsFileTime` не гарантирует, что другие библиотеки и системные API Horizon совместимы с Windows 7.
- Сборка принудительно выбирает OpenGL. Наличие Direct3D 11 в DxDiag само по себе не доказывает поддержку OpenGL или DirectX 12.
- Архив содержит клиентский EXE и файлы запуска, но не является полной portable-игрой. Horizon должен быть подготовлен официальным лаунчером: нужны его игровые файлы и `horizon-resources.json`.
- Не удаляйте и не заменяйте файлы обычной установки Horizon.
- Успешная компиляция на GitHub Actions ещё не означает, что программа запустится на Windows 7: это проверяется только на самом ноутбуке.
